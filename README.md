# DM Screen

A Dungeon Master's dashboard for in-person D&D: combat tracker with auto-sorted initiative, character sheets, monster stat blocks, a projector/TV table view with fog of war, dice, random tables, handouts, weather and sound.

## Folders

| Folder | What it is |
|---|---|
| `web/` | The DM Screen as a single HTML file. Open it in a browser; without a server it saves in that browser. |
| `local-edition/` | Runs the DM Screen from your laptop so players join from phones on your Wi-Fi with a 4-digit code. Python 3, no installs. See `READ ME FIRST.txt`. |
| `camera-kit/` | Python + OpenCV experiment: projector map that reacts to ArUco-tagged Lego minifigs seen by a webcam. |

## Table screen

Open the DM Screen again with `#table` at the end of the address, move that window to the projector or TV, and click Full screen.
